# SleepLess

<img src="docs/icon_on.png" width="48" alt="Увімкнено"> <img src="docs/icon_off.png" width="48" alt="Вимкнено">

Маленька програма в треї Windows, яка не дає комп'ютеру засинати.
Один клік по значку вмикає режим, ще один вимикає.

## Можливості

- **Клік по значку** вмикає або вимикає «не давати спати». Бурштинове око означає, що сон заборонено, сірий місяць — що комп'ютер може спати.
- **Увімкнути на…** 30 хв, 1, 2, 4, 8 год або без обмеження. Коли час вийде, програма покаже сповіщення.
- **Не гасити екран** (типово увімкнено). На ноутбуках із Modern Standby екран, що погас через простій, одразу присипляє систему, тож заборони самого сну мало.
- **Лише коли від мережі.** На батареї програма не заважає системі спати.
- **Поки працює Claude Code** (типово увімкнено). Поки запущено `claude.exe` (CLI) і ноутбук від мережі, система не спить, навіть коли основний режим вимкнено. Десктопний застосунок Claude не враховується.
- **Запускати з Windows**, без прав адміністратора (запис у `HKCU\...\Run`).

Налаштування зберігаються в `%APPDATA%\SleepLess\settings.json`. Друга копія програми не запускається.

## Як це працює

Програма використовує два механізми одночасно:

1. `SetThreadExecutionState` з `ES_SYSTEM_REQUIRED` і `ES_DISPLAY_REQUIRED`. Це стан потоку, і сторонній код у тому самому потоці може його мовчки скинути, тому програма повторює його кожні 5 с, а не ставить один раз.
2. `PowerCreateRequest` / `PowerSetRequest`: запит живлення на рівні процесу. Його видно в `powercfg /requests` (команда потребує прав адміністратора).

Закриту кришку й кнопку живлення програма не перебиває.

## Встановлення

Завантажте `SleepLess.exe` з [Releases](../../releases) і запустіть. Встановлювати нічого не треба.

Windows 11 ховає нові значки в прихований список біля годинника. Перетягніть значок на панель, щоб він був завжди видимий.

Exe не підписаний, тож SmartScreen може попередити при першому запуску: «Докладніше → Все одно запустити».

## Збірка з вихідного коду

Потрібні Python 3.10+, PySide6, PyInstaller і Pillow.

```
pip install PySide6 pyinstaller pillow
python sleepless.py          # запустити без збірки
python check_sleepless.py    # перевірки: ПРОЙДЕНО / НЕ ПРОЙДЕНО
python build.py              # dist\SleepLess.exe
```
